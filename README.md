# Buzdolabı Işığı Yüksek Mahkemesi

> Kapak açıldığında ışık yanar. Kapak kapanınca kimse görmez. Bu bir fizik problemi değil, yargı yetkisi problemidir.

Bu depo, Türkiye Cumhuriyeti sınırları içindeki tüm buzdolaplarının iç ışığına dair nihaî ve bağlayıcı içtihat üretir. Süt itiraz edemez. Yoğurt muhalefet şerhi düşebilir, dikkate alınmaz.

## Neden var?

Çünkü biri kapıyı kapattı ve ışığın hâlâ yanıp yanmadığını sordu. Bilim "sensör var" dedi. Mahkeme "sensör tanık değil, taraftır" dedi. Dava açıldı. Dava kapanmadı. Peynir bekliyor.

## Kurulum

Python 3 yeter. Bağımlılık yok. Elektrik faturası ayrı.

```bash
python3 mahkeme.py
python3 mahkeme.py "gece 03:14, kapak aralık, sucuk tanık"
```

## Yargılama usulü

1. Başvuru dilekçesi ağzından kaçan bir cümledir.
2. Heyet üç üyeden oluşur: Ampul, Kapı Contası, Raftaki Hardal.
3. Karar rastgeledir ama gerekçe ciddidir. Bu ülkenin en dürüst kurumu budur.
4. Temyiz yolu kapaktır. Kapatırsan dosya düşer, açarsan dosya yeniden doğar.

## Hukuki uyarı

Bu yazılım bir mahkeme değildir. Kararları buzdolabına uygulamak isteğe bağlıdır, süte uygulamak ise kaderdir. Copilot bu davaya müdahil olmak istedi, söz hakkı tanınmadı: tanık sıfatı yok, sadece otomatik tamamlama sıfatı var.

## Gizli dosya

`gizli/ara-karar.txt` duruşma tutanağının kamuoyuna açılmayan kısmıdır. Açmak serbest, anlamak opsiyoneldir, dağıtmak mahkemenin işi değil.
